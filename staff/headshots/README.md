# Staff Headshots

This folder contains approved staff headshots for Omega Solutions' public branding, email signatures, websites, and other authorized communications.

Use the public URL when embedding a headshot in a website or email signature.

## Adding a Headshot

- Add only a photo approved for public use.
- Use the staff member's name in a URL-safe filename, such as `First-Last.jpg`.
- Keep the original image unless an optimized version is explicitly needed; use a distinct filename for alternate sizes or crops.
