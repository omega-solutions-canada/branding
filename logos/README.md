# Logo Assets

Store only approved Omega Solutions logo files in this directory.

## Directories

- `icon/` – Square or compact icons
- `rectangle/` – Horizontal/rectangular logos
- `signature/` – Optimized assets intended for email signatures
- `source/` – Approved vector or editable source files

## Export Guidelines

For each commonly used logo, retain:

- A high-resolution transparent PNG
- A smaller optimized PNG where useful
- An SVG when it is approved and appropriate for web use
- The authoritative source file, when public distribution is permitted

For HTML email signatures, use PNG rather than relying exclusively on SVG support.

## Naming Examples

```text
Omega-Icon-Light.png
Omega-Icon-Dark.png
Omega-Logo-Rectangle-Light.png
Omega-Logo-Rectangle-Dark.png
Omega-Logo-Signature.png
```

Avoid spaces, parentheses, dates, and words such as `final`, `new`, or `latest` in published filenames.
